# Правила работы в этом репозитории

Сайт frnkness.ru: пуш в `main` автоматически публикует его через GitHub Actions.
Админка (`admin.html`) коммитит прямо в `main` на GitHub.

## Обязательно

1. **Перед началом работы** — `git checkout main` и `git pull`: админка коммитит
   в GitHub напрямую, локальная копия может отставать. Если есть несохранённые
   локальные изменения или pull не проходит — ничего не удалять, не делать force,
   показать владельцу.
2. **Никаких команд Supabase** — `db push`, `functions deploy`, `secrets`, `link`
   и любых других, которые трогают боевой проект. Только готовить файлы
   (миграции, код функции) и в конце дать владельцу список команд в правильном порядке.
3. **Ничего не мержить и не пушить в `main` без явного «да» владельца.** Работать
   в отдельной ветке. Никаких `--force`.
4. **Не писать shell-команды с обратными кавычками внутри двойных кавычек** — bash
   выполняет их как команды. Правки файлов — только через редактор файлов, а не
   через sed/скрипты в командной строке.
5. **Статистика привязана к индексу трека** (ключ прослушивания
   `<releaseId>-<индекс трека>`): не менять id релизов, состав и порядок треков
   существующих релизов. Это же проверяют `checkRegistryChange` в
   `supabase/functions/_shared/rules.ts` и функция `admin-content`.

## Формат текстов (`lyrics/**/*.txt` и `.lrc`)

1. **Каждая строка начинается с заглавной буквы**, в том числе строки в скобках
   (`(Ладно, я вас наебываю)`) и продолжения многострочной реплики. Исключения —
   намеренно строчные имена и названия (`twizzyRRich`, `nikanora` и т. п.);
   строки, начинающиеся с цифры (`26, сука…`, `-30 — …`), не меняются.
2. **В конце строки нет `,` `.` `;` `:` `—`.** `?` и `!` можно. Точка допустима
   только как часть сокращения (`и т.д.`, `C.P.`), многоточие `…` — можно.
3. **Метки секций — в квадратных скобках на отдельной строке**: `[Припев]`,
   `[Куплет 1]`, `[Скит — «Кофикс»]`.
4. **`.lrc` совпадает с `.txt`**: текст каждой строки `.lrc` (после таймкода)
   дословно равен строке из `.txt`. Правишь `.txt` — правь ту же строку в `.lrc`,
   таймкоды не трогай.
5. Разборы (`.notes.json`) сопоставляются со строками без учёта регистра и знаков
   по краям, поэтому смена регистра их не ломает.

PDF с текстами — `lyrics-books/<releaseId>.pdf` (при замене из админки —
`<releaseId>-ГГГГММДД.pdf`, чтобы не мешал кэш). При скачивании файл получает имя
«frnk ness — <Название релиза> (тексты).pdf».

## Проверки перед коммитом

`npm run typecheck`, `npm run test:run`, `npm run build` (сборка заодно проверяет,
что код админки не попал в бандл сайта и в precache service worker).
Для админки — `npm run test:e2e` (Supabase и GitHub замоканы).
