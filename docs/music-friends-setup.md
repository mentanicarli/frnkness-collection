# Запуск «Музыки и друзей» (этап 3): пошаговая инструкция

Что появится: избранное (сердечко у трека), плейлисты со своими обложками
и публичностью, «мой топ», друзья с заявками, «что сейчас слушает»,
страница пользователя по нику; в админке — избранное, плейлисты и друзья
в карточке пользователя и модерация плейлистов.

**Порядок:** сначала база и функции, потом мерж. Новый сайт без миграции
не покажет избранное и плейлисты, а старый сайт новую миграцию просто не
замечает — поэтому база идёт первой.

Терминал — в папке проекта, ветка `feature/music-friends`.

## Шаг 1. Подключиться к проекту

```bash
npx supabase@latest link --project-ref momcakikuivtvxkmgjhx
```

(Если CLI попросит войти — `npx supabase@latest login`.)

## Шаг 2. Миграция

Сначала посмотреть, что будет применено (ничего не меняет):

```bash
npx supabase@latest db push --dry-run
```

В списке должна быть **одна** миграция: `20261007120000_music_friends.sql`.
Если есть что-то ещё — остановись и пришли мне вывод. Если всё так:

```bash
npx supabase@latest db push
```

Миграция создаёт таблицы `favorites`, `playlists`, `playlist_tracks`,
`friendships`, `now_playing`, функции для сайта и админки и приватный бакет
`playlist-covers`. Существующие данные не трогает.

## Шаг 3. Функции

Изменились две функции: при удалении аккаунта они удаляют и обложки
плейлистов, а `admin-users` умеет модерировать плейлисты.

```bash
npx supabase@latest functions deploy admin-users --no-verify-jwt --use-api
```

```bash
npx supabase@latest functions deploy account --no-verify-jwt --use-api
```

Остальные функции (`admin-content`, `register`, `recovery-request`) не
менялись — их деплоить не нужно. Секреты новые не нужны.

## Проверка

- Сердечко у трека в треклисте, на странице трека, в мини- и
  полноэкранном плеере — нажатие меняет его сразу; «Избранное» в меню
  профиля: «Слушать», «Перемешать», «Поток по избранному».
- «В плейлист» → «Новый плейлист»; на странице плейлиста — перестановка
  перетаскиванием и стрелками, удаление трека, «Публичный», своя обложка и
  «Вернуть коллаж», удаление плейлиста.
- Со второго аккаунта (или с аккаунта друга): поиск по нику на странице
  «Друзья», заявка → у другого красная цифра на аватаре в шапке → принять.
  После этого на странице друга видны избранное, плейлисты, топ и — если он
  что-то слушает — «Сейчас слушает».
- Админка → «Пользователи» → карточка: избранное, плейлисты, друзья;
  переименовать плейлист, удалить обложку, удалить плейлист.
